# オリジナル長文21編

`typing_long_passages_21.json` はユーザー提供ファイルをバイト単位で保存した原本です。SHA-256: `c6826cc353e4e1f8b1ad5b851c45ea5a0c9dc257f19255b864a074bf7b5642ba`。本文・分類・難易度・文字数・順序を変更しません。e-typingの文章や画面素材は含みません。

原本には読みがないため、`readings.json` に追加の読みを保存しています。`〈本文|ひらがなの読み〉` が対応区間で、それ以外のかなと句読点は原文どおりです。カタカナはひらがなへ正規化します。助詞は表記どおり「は」「へ」「を」、長音は「ー」を入力します。下書きにfugashi 1.5.2 / unidic-lite 1.0.8を使い、博士課程（はくし）、一日（いちにち）、一行（いちぎょう）、充放電、年号、二十歳などの文脈に合わない読みを補正しています。読みの修正はこのファイルに行います。

`python3 scripts/import-original-long.py` は原本SHA-256・IDと順序・全文と文字数の一致・漢字の読み漏れを検査し、全文を1つの入力対象として生成します。`annotated` 配列の区切りは編集用で、出題切り替えには使いません。生成物は `src/data/generated/originalLong.json`。実行時・再生成時に辞書やネット接続は不要です。

# スコアと称号

point・正確率・称号・CPUプリセットの計算方法です。概要は [README](../README.md#スコアと称号) を参照してください。

## point

```text
point = floor(正打鍵KPM × 補正正確率²)
補正正確率 = 正打鍵数 / (正打鍵数 + 加重ミス数)
```

- **加重ミス数**：同じ箇所の連続ミスを、1回目から順に重み 1・0.75・0.5・0.35・0.25（以降も0.25）で加算します。正しい打鍵で連続回数をリセットします。
- pointに上限はありません。
- 計算式は [福島高専のe-typing活用報告（2019、p.40）](https://www.jstage.jst.go.jp/article/rrie/1/0/1_39/_pdf/-char/ja) を参考にしています。連続ミスの減点補正と独自の称号を使うため、e-typing の公式スコアとは別物です。
- 旧方式で保存した記録は当時のミス数でpointを計算し、「旧ミス方式」と表示します。

## KPMと正確率

| 指標              | 計算                                                      |
| ----------------- | --------------------------------------------------------- |
| KPM               | 正しく受け付けた実打鍵数 ÷ 実測分数（休止時間を除く）     |
| タイプウェルのKPM | 固定の基準打鍵数（ローマ字400 / かな280）÷ 実測分数       |
| 正確率            | 正打鍵 ÷（正打鍵 + 実ミス）× 100。連続ミスも1打ずつ数える |
| 実ミス率          | 実ミス ÷（正打鍵 + 実ミス）× 100                          |

- 表示する正確率とCPU対戦の95%判定は実ミスを使います。補正正確率はpoint計算の内部値で、表示しません。
- 詳細分析・速度グラフのKPMは、全モードで有効な別綴りを含む実打鍵数を使います。

## 称号

称号は「接頭辞 + 動物名」です（例：「星々に祝福されしチーター」「精緻なキツネ」）。過去の記録にも現在の称号を適用します。

- 人間の特定集団を測定した値ではなく、ゲーム用の設定です。

### 接頭辞

実ミス率で決まります。0%は専用区分で、それ以外は前の上限を超え、表の上限を含みます（0.5%ちょうどは「至高の」）。判定には丸める前の値を使い、まだ打っていない状態では付けません。

| 実ミス率   | 接頭辞           |
| ---------- | ---------------- |
| 0%         | 星々に祝福されし |
| 0%超〜0.5% | 至高の           |
| 0.5%超〜1% | 研ぎ澄まされた   |
| 1%超〜2%   | 精緻な           |
| 2%超〜3%   | 堅実な           |
| 3%超〜5%   | 歴戦の           |
| 5%超〜8%   | 荒削りな         |
| 8%超〜12%  | 暴走する         |
| 12%超      | 混沌の           |

実ミス数が残っていない旧記録は、保存されたミス箇所数で代用し「旧集約ミス率」と表示します。

## 速度統計

- 速度グラフは完全な1秒区間の実打鍵KPMを使い、無入力の1秒は0、末尾の1秒未満は除外します。
- 過去順位は**5秒移動平均**の最高・最低速度で比較します（最低速度も高いほど上位）。5秒未満の記録は対象外です。
- ラン内の「5秒移動平均」と、記録間の「直近5回移動平均」は別の指標です。
- タイムロスは、正打鍵の打鍵間隔の中央値を超えた待ち時間の目安で、ミスが原因と断定する値ではありません。

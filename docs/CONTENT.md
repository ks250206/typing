## 共通の仕様

- 本文は漢字かな混じりで、判定には手動で用意・確認した読みを使います。漢字の読みを推測で分割しません。
- 本文・ひらがな・ローマ字は同じ単語単位で、色分け・余白・入力済み単語の消去がそろいます。
- ランダム出題のセットは、同じセット・シード・出題バージョンなら同じ問題・順序になり、配列を変えても変わりません。
- 全セットを通常練習・CPU対戦の両方で使えます。CPU対戦では、通常練習の15問とは別にBO7全体の最大133問（7ラウンド×19問）をシードから用意します。
- 元サイトの画面・画像・スクリプトは収録していません。

## オリジナル長文

各編の全文を1問として入力します。句点での切り替えや次の文の表示はなく、本文は折り返さない1行で横に送ります。

- ユーザー提供の21編（7テーマ × 初級・中級・上級）。原本 `typing_long_passages_21.json` を変更せず保存し、読みは別ファイルで管理しています（[読みデータの管理](../data/sources/original-long/README.md)）。
- 独自解説5編：キュリー夫人、ポエニ戦争、ソクラテス、湯川秀樹、フォンノイマン（各676〜727文字）。原稿は [data/sources/themes](../data/sources/themes/README.md)。

## 公的文書（日本国憲法）

[衆議院掲載の日本国憲法](https://www.shugiin.go.jp/internet/itdb_annai.nsf/html/statics/shiryo/dl-constitution.htm) と照合しています。表示は原文の歴史的仮名遣い（わたつて・やう・ゐる 等）を保ち、入力は現代の読み（わたって・よう・いる 等）を使います。

- **前文**：4段落・全9文を省略せず順に入力します。公布文と条文は含みません。

## タイプウェル

単語を復元抽出でランダムに選び、半角スペースでつないで出題します。ローマ字配列は国語R相当の**400打**、かな入力は国語K相当の**280打**（濁点別打鍵を含む）で、最後の単語の途中でも終了します。出題は入力前にすべて確定し、別の有効な綴りを使っても終了位置・基準打鍵数は変わりません。

[非公式ブラウザ版の出題・入力処理](https://github.com/fiore57/typewell-in-browser/blob/main/src/lib/typing.ts) と [タイプウェル国語R/Kの種目・打鍵数の記録](https://w.atwiki.jp/typer/pages/51.html) を参考にしています。元ソフトの完全移植ではありません。

## RTC

### RTC年度別ワード

ユーザー提供の `RTC2018-Words.zip`・`RTC2019word5.zip`・`RTC2023word2.zip`・`RTC2024word.zip`・`RTC2025word.zip` のXML全20ファイル・計5,994フレーズです。[Weather Typing公式のワード生成方法](https://denasu.com/software/weathertyping/customize.html) に沿って、前半・後半の各パートから1フレーズずつ独立に選んで連結します（区切りの空白は追加しません）。通常練習は15問で、CPU対戦の先頭15問と一致します。

ZIPは再配布の許諾を確認できていないため、リポジトリに含めていません。入力用の読みはカタカナをひらがな、英字を小文字、全角英数記号を半角にそろえます。中点はローマ字入力で `/`、かな入力で `Shift + Slash` です。

### RTCオリジナル

日常・自然・旅・読書・音楽・練習などの独自短文200文です。公式RTCのワードとは別のセットです。通常練習は重複なしの15問、CPU対戦は200文をシャッフルして出題します。

### RTC風（AI・機械学習・LLM）

前半100・後半100のフレーズを組み合わせた10,000通りから、シードで15問を生成します。

## 60秒トレーナー

カウントダウン終了から60秒間、1文ずつ表示して正打鍵数を計測します。収録文を1回ずつ打つと1周で、周ごとに新しくシャッフルし、周の境目でも同じ文は続きません。

| 文章セット         | 収録数 | 出典                                                                                               |
| ------------------ | -----: | -------------------------------------------------------------------------------------------------- |
| さくさくタイピング |     15 | ユーザー提供の本文と読み（[参照先の単語帳](https://ankey.io/wordbooks/cuet1ri9io6g02p7bm0g)）      |
| 高速タイピング     |     18 | [タイパー養成所](http://typing.tsurizamurai.com/daken_010/type.cgi) の保存HTMLから本文・読みを抽出 |
| 長文鍛錬用         |     15 | [タイパー養成所](http://typing.tsurizamurai.com/daken_003/type.cgi) の保存HTMLから本文・読みを抽出 |
| シェイクスピア     |     24 | 独自原稿                                                                                           |
| ノーベル賞         |     24 | 独自原稿                                                                                           |

保存HTMLからは本文・読み・文字対応・制限時間だけを抽出し、広告・画像・スクリプトは取り込んでいません。

## English

英語は大文字・小文字・句読点・半角スペースをそのまま入力します。かな配列は使わず、選択時にJIS英数へ切り替えます。

| 区分           | 内容                                                               | 出題              |
| -------------- | ------------------------------------------------------------------ | ----------------- |
| オリジナル     | 4編                                                                | 全文を一文ずつ    |
| オリジナル長文 | 2編                                                                | 全文を1問として   |
| e-typing       | 19タイトル・1,540文（2012年の第1〜38回。同タイトルは最新回を優先） | 重複なし15問      |
| TypeWell英単語 | TWEW215の基本・拡張A–F / G–P / Q–Z の4辞書・6,000語                | スペース込み400打 |

e-typing と TypeWell は [physics-HTFI / TypeLighter](https://github.com/physics-HTFI/TypeLighter) の付属ワードです。出典・取得コミット・SHA-256・ライセンス原文は [data/sources/english](../data/sources/english/README.md) にまとめています。
